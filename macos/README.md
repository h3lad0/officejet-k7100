# Драйвер HP Officejet K7100 / K7103 / K7108 для современных macOS

Замена официального драйвера HP *Officejet Full Feature Software v9.7* (январь 2008,
macOS 10.3.9–10.5), который на современных системах не работает.

## Почему старый драйвер не работает

В `HP_Installer_OJK7100_v9.7.dmg` фильтр печати
(`/Library/Printers/hp/cups/Officejet.driver/Contents/MacOS/Officejet`) и все библиотеки
собраны только под **PPC и i386**. 32-битный код не запускается начиная с macOS 10.15,
а Rosetta 2 на Apple Silicon i386 не поддерживает. Сам PPD из пакета пригоден, но
ссылается на этот фильтр.

## Что сделано

| Компонент | Источник |
|---|---|
| Фильтр `hpcups` (растр CUPS → PCL3GUI) | HP HPLIP 3.26.4 + расширения [src/k7100_ext.cpp](src/k7100_ext.cpp), universal (arm64 + x86_64), macOS 11+ |
| Фильтр команд `commandtok7100` | [src/commandtok7100.cpp](src/commandtok7100.cpp): чистка, выравнивание, уровни чернил |
| Утилита `k7100` | [src/k7100](src/k7100), командная строка |
| PPD | HPLIP `hp-officejet_k7100.ppd` + параметры драйвера HP ([tools/patch_ppd.py](tools/patch_ppd.py)) |
| Иконка, ICC-профили | оригинальный DMG HP |

HPLIP — открытый драйвер самой HP; K7100/K7103/K7108 поддерживаются в нём
без бинарных плагинов, на том же языке принтера PCL3GUI, что и в старом драйвере HP.
K7100 — VIP-принтер: он получает RGB и сам выполняет цветоделение, поэтому многие
настройки драйвера HP были просто командами принтеру. Их коды взяты из данных
старого драйвера (`Elion.xml`, `Officejet_H7100.xml`, `PDLData.xml`).

### Окно печати

- **Тип бумаги** — все 32 типа из драйвера HP, включая «Толстая обычная бумага»,
  Premium, фото глянцевая/матовая/сатин, брошюрная, открытки, этикетки, термоперенос,
  «Автоматически» (датчик бумаги принтера). Для каждого принтеру уходят те же коды,
  что отправлял драйвер HP: тип носителя PCL (`ESC&l#M`) и подтип VIP (`ESC*o5W 0D 03`) —
  от них зависят количество чернил, время высыхания и скорость. Двусторонняя
  печать запрещена для бумаги, для которой её запрещала HP.
- **Качество** — пять режимов HP: Быстрый черновик, Быстрый обычный, Обычное,
  Наилучшее, Максимальное разрешение (1200 dpi).
- **Источник бумаги** — Автовыбор, Лоток 1, Ручная подача.
- **Параметры цвета** — цветовой режим (ColorSmart/sRGB, Adobe RGB, ColorSync с
  профилями HP), количество чернил (−2…+2), насыщенность, яркость, цветовой тон,
  коррекция голубого/пурпурного/жёлтого/чёрного (−50…+50), зеркальное отражение.
  Регулировки применяет сам принтер: hpcups отправляет их командами `ESC*o5W`,
  как драйвер HP.
- **Пресеты** HP: «Фото», «Фото на обычной/фото/матовой бумаге» и их варианты «высокое качество».
- **ColorSync** — профили HP для Premium Plus Photo (в т. ч. глянцевая и сатин) и
  Premium Photo для трёх комплектов картриджей; применяются в режиме «ColorSync».
- Интерфейс драйвера переведён на русский.

### Чернила и состояние принтера

Принтер сообщает о себе через IEEE 1284 Device ID: установлены ли картриджи,
исправны ли они, флаги «мало/нет чернил», открыта ли крышка, есть ли бумага, замятие.
Это отображается в **«Принтеры и сканеры» → «Параметры и материалы» → «Уровень
расходных материалов»** и как предупреждения принтера.

Сам уровень чернил K7100 знает только для оригинальных картриджей HP (по счётчику
в чипе). Для перезаправленных и совместимых картриджей он сообщает «0/не HP»,
поэтому драйвер **оценивает расход сам**: считает покрытие каждой страницы по
каналам K/C/M/Y с поправкой на режим качества и сравнивает с номинальным ресурсом
картриджей HP 94/96 (480/860 страниц) и HP 95/97 (260/450 страниц) при 5 %
заполнении. Модель картриджа выбирается в «Параметры и материалы → Параметры».
Оценка хранится в `/private/var/spool/cups/cache/HP_K7100-<очередь>.ink`; после
заправки или замены её нужно сбросить:

```bash
/Library/Printers/HP_K7100/bin/k7100 reset-ink black     # или color, all
```

Если в чипе есть настоящий уровень (оригинальный картридж HP), показывается он.

### Обслуживание

- **Чистка печатающих головок** — кнопка «Очистить печатающие головки» на вкладке
  «Утилита» в «Параметры и материалы» (уровень 1).
- Из терминала:

```bash
/Library/Printers/HP_K7100/bin/k7100 status            # состояние и уровни
/Library/Printers/HP_K7100/bin/k7100 clean 2           # чистка уровня 1, 2 или 3
/Library/Printers/HP_K7100/bin/k7100 align             # автоматическое выравнивание
```

Команды — те же последовательности PML, которыми HPLIP обслуживает этот принтер.

Не восстановлено: Photo Fix (закрытая библиотека HP), панели HP в окне печати,
HP Device Manager, ПО Photosmart. Ручную двустороннюю печать можно сделать
средствами macOS: «Обработка бумаги» → сначала нечётные, затем чётные страницы.

## Установка

```bash
sudo installer -pkg HP-Officejet-K7100-macOS-1.1.0.pkg -target /
```

Пакет не подписан сертификатом Apple Developer, поэтому двойной щелчок по нему
Gatekeeper заблокирует; используйте команду выше или «Открыть» в контекстном меню Finder.

Затем: **Системные настройки → Принтеры и сканеры → Добавить принтер** → выбрать
K7100 (USB) → в поле «Использовать» выбрать **HP Officejet K7100 (hpcups 1.1.0)**.

Добавить очередь из терминала (USB-адрес можно взять из `lpinfo -v`):

```bash
lpadmin -p K7103 -E -v "usb://HP/Officejet%20K7100?serial=..." -P "/Library/Printers/PPDs/Contents/Resources/HP Officejet K7100 (hpcups).ppd.gz"
```

Для сетевого подключения через JetDirect используйте `socket://<ip>:9100`.

Удаление: `./uninstall.sh`.

## Сборка

Нужны Xcode Command Line Tools. Для иконки принтера и профилей ColorSync положите
`HP_Installer_OJK7100_v9.7.dmg` в `macos/vendor/` (или укажите путь в `HP_DMG=...`);
без него пакет соберётся без них. Затем:

```bash
cd macos
./build.sh
```

Скрипт скачивает исходники HPLIP и IJG libjpeg в `sources/` (контрольные суммы в
`sources/SHA256SUMS`), собирает статическую libjpeg и `hpcups`, проверяет PPD
через `cupstestppd` и кладёт пакет в `dist/`.

Правки исходников HPLIP делает [tools/patch_hplip.py](tools/patch_hplip.py); каждая
правка должна найти своё место ровно один раз, иначе сборка останавливается:

- вызовы `k7100_ext` в `HPCupsFilter.cpp` и `Pcl3Gui2.cpp` (параметры задания,
  команды VIP, зеркальное отражение, учёт расхода чернил, статус);
- `common/utils.h` переименован: на APFS без учёта регистра он перекрывался `prnt/hpcups/Utils.h`;
- имена объектных файлов включают путь (`utils.o` ≠ `Utils.o`);
- `compat/malloc.h` вместо отсутствующего в macOS заголовка;
- без D-Bus и без бинарного `libImageProcessor` (он нужен только LaserJet ZJStream).

## Что проверено

- `hpcups` и `commandtok7100` запускаются на arm64 и под Rosetta (x86_64);
- конвейер macOS `cgpdftoraster` → `hpcups` для A4, A3, Super B (13×19"), всех
  режимов качества, цвета и оттенков серого;
- коды в PCL для типов бумаги, источников, качества и цветовых настроек совпадают
  с данными драйвера HP (проверено на выходе hpcups, в т. ч. `ESC&l-1M` для
  «Автоматически»);
- байты команд чистки и выравнивания совпадают с генерируемыми HPLIP;
- разбор Device ID совпадает с HPLIP на реальном K7100 и на смоделированных
  ошибках (крышка, бумага, мало чернил); учёт и сброс оценки чернил;
- `cupstestppd` без ошибок (остаются предупреждения HPLIP о нестандартных
  именах размеров бумаги);
- на реальном HP Officejet K7100 по USB на macOS 26 (Apple Silicon): печать,
  уровни чернил и состояние в «Параметры и материалы», чистка головок, типы
  бумаги и параметры цвета.

Не проверялось отдельно: насколько точно оценка расхода совпадает с реальным
остатком чернил — её стоит сверить на первых картриджах.

## Лицензии

`hpcups` — HPLIP, лицензия в `/Library/Printers/HP_K7100/COPYING-HPLIP`
(BSD/MIT/GPL по компонентам). libjpeg — Independent JPEG Group. Иконка — HP:
она не хранится в репозитории и попадает в пакет только при локальной сборке из DMG.
