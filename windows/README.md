# Драйвер HP Officejet K7100 / K7103 / K7108 для Windows 10 и 11

Установка оригинального драйвера HP на современные Windows без устаревшего
установщика *OJK7100_Full_8.exe* (2007, Windows 2000/XP/Vista).

## В чём проблема и что сделано

В `OJK7100_Full_8.exe` (200 МБ) сам драйвер занимает около 24 МБ. Это драйвер
Unidrv версии 61.063.264.22 для **x86** (`hpoh710a.inf`) и **x64** (`hpoh710s.inf`)
с подписью Microsoft WHQL. На Windows 10/11 не работает установщик HP
(Setup.exe/hpzsetup.exe проверяет версию ОС и тянет за собой ПО Photosmart), а сам
драйвер — пользовательского режима, с поддержкой Vista x64 — штатно ставится
через `pnputil`.

Скрипты этой папки:

- извлекают из пакета HP только файлы драйвера;
- **не изменяют их**: любое изменение INF или DLL сломало бы подпись WHQL, и
  Windows отказалась бы ставить драйвер;
- регистрируют драйвер в хранилище драйверов, после чего Windows сама
  создаёт принтер при подключении K7100 по USB (ID `USBPRINT\HPOfficejet_K7100DAA0`);
- по желанию создают сетевую очередь (HP JetDirect, порт 9100).

Пересобрать сам драйвер HP под новые Windows невозможно: его рендер-плагин,
процессор печати и монитор языка — закрытые бинарные файлы HP. Поэтому
**Windows на ARM64 не поддерживается**: спулер ARM64 не загружает x64-плагины.

## Установка

### Вариант 1: на Windows

1. Скачайте с сайта HP `OJK7100_Full_8.exe` и положите рядом с `install.ps1`
   (или в `windows/vendor/`).
2. Запустите `install.cmd` (он запросит права администратора).

Пакет HP распаковывается встроенным в Windows `tar.exe`, а если не получится —
через [7-Zip](https://www.7-zip.org), если он установлен.

Сетевой принтер:

```powershell
.\install.ps1 -PrinterIP 192.168.1.50
```

### Вариант 2: подготовить архив на macOS/Linux

```bash
cd windows
./prepare.sh path/to/OJK7100_Full_8.exe   # нужен 7-Zip: brew install sevenzip
```

Получится `dist/HP-Officejet-K7100-Windows.zip` (≈24 МБ: скрипты + папка `driver`).
Перенесите его на Windows, распакуйте и запустите `install.cmd`.

Архив содержит файлы HP, поэтому **не публикуйте его** (например, в GitHub Releases):
у каждого пользователя он собирается из его собственной копии пакета HP.

### Удаление

```powershell
.\uninstall.ps1
```

## Ограничения

- Устанавливается только драйвер печати. HP Toolbox, сканирование и ПО Photosmart
  не ставятся (у K7100 нет сканера; уровень чернил показывает дисплей принтера).
- Если в Windows 11 включён **режим защищённой печати Windows** (Windows protected
  print mode), сторонние драйверы, в том числе этот, отключаются. По умолчанию он выключен.
- Microsoft постепенно сворачивает поддержку сторонних драйверов печати v3. На
  Windows 11 24H2 они пока устанавливаются и работают, но в будущих версиях это
  может измениться.

## Что проверено

- состав пакета: оба INF ссылаются только на файлы, которые попадают в архив;
- каталоги `hpoh710s.cat`/`hpoh710a.cat` подписаны Microsoft (WHQL) и содержат хеши
  INF и всех файлов из CAB;
- `prepare.sh` на macOS;
- установка через `install.cmd` и печать на Windows 11 x64 с реальным K7100.

На Windows 10 и x86 не проверялось. Если что-то не так, создайте issue и приложите
журнал `%TEMP%\hp_k7100_install.log` (его пишет `install.ps1`).

`SHA256SUMS` — контрольная сумма пакета HP, для которого написаны скрипты.
